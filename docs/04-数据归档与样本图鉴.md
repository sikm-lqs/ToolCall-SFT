## 如何读一个评测案例

- **case**：官方样例经固定版本 loader 读取后的结构，或项目的评测小步记录。
- **request**：完整首请求的模型侧结构，包含 messages 和全部工具 schema；τ² 另存用户模拟器侧的首轮输入。相邻的 .prompt.txt 是本地 tokenizer 从结构化输入离线渲染的文本，并非历史网络抓包。
- **label**：上游参考、评分约束或执行成功条件。BFCL 相关性题没有标准文本，所以只记录可解码调用是否应当存在。
- **prediction**：本地已有历史输出；为空表示没找到实录。BFCL 的 prediction 往往是评分用的解析结果，不等于原始 Chat Completions 消息。多轮轨迹依赖模型行为；不补写未记录的历史请求。

## 下载与复现

在仓库根目录运行。训练源当前使用 ModelScope 的 master，因此未来重新下载不保证内容相同；精确比对以本地清单的逐文件 SHA-256 为准，不能只看分支名。ToolACE 镜像未与作者源逐条校对；Magpie 的随附数据卡与镜像许可元数据不一致。

~~~bash
mkdir -p data/manifests/download-logs
while read -r slug repo; do
  if modelscope download --dataset "$repo" --revision master \
       --local_dir "data/raw/$slug" --max-workers 4 \
       > "data/manifests/download-logs/$slug.log" 2>&1; then
    echo 0 > "data/manifests/download-logs/$slug.exit"
  else
    status=$?
    echo "$status" > "data/manifests/download-logs/$slug.exit"
    exit "$status"
  fi
done <<'SOURCES'
xlam-60k Salesforce/xlam-function-calling-60k
apigen-mt-5k AI-ModelScope/APIGen-MT-5k
toolace mlabonne/ToolACE
glaive-v2 AI-ModelScope/glaive-function-calling-v2
magpie-pro-300k Magpie-Align/Magpie-Pro-300K-Filtered
smoltalk HuggingFaceTB/smoltalk
SOURCES

runs/tools/bfcl/bin/python scripts/data-audit/training.py
runs/tools/bfcl/bin/python scripts/data-audit/evaluation.py bfcl
runs/tools/api-bank/bin/python scripts/data-audit/evaluation.py api-bank
runs/tools/tau2/bin/python scripts/data-audit/evaluation.py tau2
runs/tools/bfcl/bin/python scripts/data-audit/render_prompts.py \
  "$HOME/.cache/modelscope/models/Qwen--Qwen3.5-2B/snapshots/master"
python3 scripts/data-audit/report.py
~~~

评测导出依赖本项目已有的 BFCL、API-Bank、τ² worker 和归档 run；安装方式见[评测运行与产物](01-评测运行与产物.md)。渲染只读取 tokenizer 和 chat template，不加载模型权重。HTML 无外部依赖，完整 Prompt 和 JSON 通过本地链接打开。
