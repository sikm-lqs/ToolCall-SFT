# SFT-v1r1 清洗：工具适用性与任务组隔离

2026-11-24（Asia/Shanghai）。从冻结的 `data/processed/sft_v1r1/` 派生 `data/processed/sft_v1r1_clean/`；原 r1 与 v1 不覆盖。此轮只处理数据，不训练、不回填配额、不改已有标注。

## 处理方式

- **SmolTalk 合成负例默认不纳入。** 从单轮、短问题、可读工具描述的候选中复核 244 个不同内容的请求，按问题、候选工具的声明用途与目标回答筛选。最终批准 159 个不同内容；批准绑定完整 messages 与有序工具 schema 的 SHA-256，改动任一部分不能继承批准。实时天气类假负例（如 smoke 的 `..._00044`、`..._00040` 及正式集的 `..._02667`）明确排除；另排除少数可见的答案质量问题。其余合成负例未获批准，**不等同于都错标**。本轮未对其余来源逐条重新做语义标注。
- **切分按任务组隔离。** 验证集优先。独立核对了规范化用户轮序列（NFKC、大小写与空白归一，不含工具）、原 `dedup_signature` 和 `(source, source_id)`，验证集和 train / smoke 在三种键下交集均为 0。旧正式训练与验证的 4 组用户轮重叠已经全部消失：其中两条训练记录由任务组过滤器额外移除，其余已在合成负例筛选中移除。不声称排除了所有语义近重复或外部 Benchmark 污染。

## 冻结结果

| 切分 | 原行数 | 清洗后 | 保留 SmolTalk | `irrelevance` 标签合计 | 对应 assistant loss token 占比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 正式训练 | 25,015 | 20,947 | 134 | 682（3.26%） | 1.94% |
| smoke | 3,000 | 2,574 | 74 | 144（5.59%） | 4.37% |
| 验证 | 600 | 493 | 13 | 53（10.75%） | 7.41% |

同一内容可能同时出现在 train 和 smoke，因此 SmolTalk 分列计数不直接相加。所有保留记录与原数据逐条一致。排除台账只存样本 ID、桶、原因和内容摘要，不含训练文本。

清洗版不再有原版的 19% 负例配比，不能作为同预算、同配比实验直接比较；尤其不建议直接用正式集开 E1。可先把它作为保守对照，若要检验原来的负例剂量，另行扩充经过核实的难负例，同时用应调正例监控过度拒调。

## 复现与验证

从仓库根目录使用带现有 tokenizer 依赖的本地环境：

```bash
PYTHONPATH=src runs/tools/bfcl/bin/python -m toolcall.data.clean_sft_v1r1
```

[复跑入口](../../src/toolcall/data/clean_sft_v1r1.py) 默认读取[审核清单](../../configs/data/sft_v1r1_review.json)，输出目录已存在时会拒绝覆盖。清洗版的三个 JSONL、训练模板和排除台账 SHA-256 均通过 `verify_data_manifest`。CPU 单测 17/17 通过。
